# Fleet SDK Tutorial

Concise learning path for off-chain Ergo transactions with Fleet SDK.

**Prerequisites:** Node.js 18+, TypeScript, and testnet ERG. Never hardcode mainnet keys.

## Chapters

1. [Send transactions to wallets](./01-send-to-wallet.md) — inputs, outputs, fee, change
2. Mint (EIP-004) and burn tokens *(planned)*
3. Boxes: retrieval, contracts, registers, data-inputs *(planned)*
4. Signing: reduced transactions and ErgoPay *(planned)*
5. Examples: timelock and multi-interaction *(planned)*

Each chapter explains the concept, includes plug-and-play TypeScript, and lists common pitfalls.
